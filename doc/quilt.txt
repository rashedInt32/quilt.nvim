*quilt.txt*  Edit many files from one buffer

==============================================================================
CONTENTS                                                      *quilt*

A quilt is one buffer that holds editable excerpts from many files. Every
edit goes straight to the file's buffer. |:w| in the quilt writes every file
you changed, with its normal autocmds.

Requires Neovim 0.11 or newer. `rg` for |:Quilt-grep|, `git` for |:Quilt-git|.

==============================================================================
COMMANDS                                                      *:Quilt*

:Quilt                  Quilt of the quickfix list. Same as `:Quilt qf`.
:Quilt qf               Quilt of the quickfix list.
:Quilt refs             LSP references of the symbol under the cursor.
:Quilt grep {pattern}   `rg --vimgrep {pattern}` in the cwd.  *:Quilt-grep*
:Quilt diagnostics [error|warn|info|hint]
                        Diagnostics at or above the severity.
:Quilt git [ref]        Changed hunks from `git diff -U0 [ref]`. With no
                        ref, unstaged changes.                 *:Quilt-git*
:Quilt refresh          Reread every excerpt from its file.

==============================================================================
KEYS                                                          *quilt-keys*

All keys are buffer-local to the quilt. Set any to `false` in |quilt-config|.

<CR>        open the file at this line
]] [[       next / previous excerpt
+ -         more / less context around this excerpt
zd          drop this excerpt from the quilt; the file is untouched
K           hover
gd gri      definition / implementation; inside the quilt when it's there
grn         rename
gra         code action
grr         references, as a new quilt

The quilt also maps `o`, `O`, `u`, `U`, `<C-r>`, `g-` and `g+` to themselves.
They record which excerpt a new line at an edge belongs to.

==============================================================================
EDITING                                                       *quilt-editing*

A new line between two excerpts goes to the excerpt the cursor was in: `o`
on the last line of one excerpt adds to that file, `O` on the first line of
the next adds to that one. Deleting every line of an excerpt deletes them from
the file and hides the excerpt. |u| brings it back to its own file.

`+`, `-`, `zd`, `:Quilt refresh` and |:e!| in the quilt change only what it
shows, so they clear the quilt's undo history. Each file keeps its own.

Known limits:
- |:m| across an excerpt edge carries the edge with the line. The headers
  show where it went, and |:w| writes what you see.
- When a file and the quilt change the same excerpt in the same moment, the
  file's version wins, with an error notice.

==============================================================================
CONFIG                                                        *quilt-config*

>lua
  require("quilt").setup({
    context = 3,         -- lines of context around each hit
    max_excerpts = 200,  -- refuse to build a bigger quilt
    keys = { open = "<CR>", next = "]]", prev = "[[", expand = "+",
             shrink = "-", drop = "zd", hover = "K", definition = "gd",
             implementation = "gri", rename = "grn", code_action = "gra",
             references = "grr" },
  })
<
Highlight groups: `QuiltHeader`, `QuiltHeaderPath`, `QuiltHeaderLnum`,
`QuiltLineNr`.
